# מוריד הסרטונים

תוכנה קטנה ל-Windows שמורידה סרטון מיוטיוב כ-MP4 (וידאו) או כ-MP3 (שמע בלבד).

## הורדה

מורידים את הקובץ `MoridSratonim.exe` מעמוד ה-[Releases](../../releases/latest) ופותחים אותו. לא צריך להתקין שום דבר נוסף.

בפתיחה הראשונה Windows עשוי להציג "Windows הגן על המחשב שלך", כי זו תוכנה חדשה. לוחצים על "מידע נוסף" ואז על "הפעל בכל זאת".

## איך משתמשים

1. מדביקים קישור מיוטיוב. Ctrl+V עובד גם כשהמקלדת בעברית, ויש גם כפתור "הדבקה".
2. בוחרים MP4 או MP3.
3. לוחצים על "הורדה". הקובץ נשמר בתיקיית ההורדות, ואפשר לבחור תיקייה אחרת.
4. אחרי ההורדה אפשר לפתוח את התיקייה או להעתיק את הקובץ כדי להדביק אותו בצ'אט או במייל.

## טוב לדעת

- תיקיות כמו מוזיקה, תמונות ומסמכים עלולות להיות חסומות לכתיבה אם מופעלת ב-Windows "גישה מבוקרת לתיקיות". במקרה כזה בוחרים תיקייה אחרת.
- התוכנה גולשת דרך החיבור הרגיל של המחשב ולא עוקפת סינון אינטרנט. מי שגולש עם נטפרי יוכל להוריד רק סרטונים שמאושרים אצלו.
- יש להוריד רק תוכן שמותר לכם להוריד, בהתאם לזכויות היוצרים ולתנאי השימוש של יוטיוב.

## הרצה מהקוד

צריך Python 3.12 ומעלה.

```bash
pip install -r requirements.txt
python youtube_downloader.py
```

## בניית קובץ ה-exe

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name MoridSratonim --icon icon.ico --add-data "icon.ico;." --add-binary "<הנתיב אל deno.exe>;." --collect-all yt_dlp_ejs --collect-binaries imageio_ffmpeg youtube_downloader.py
```

התוכנה בנויה על [yt-dlp](https://github.com/yt-dlp/yt-dlp) ועל ffmpeg.
